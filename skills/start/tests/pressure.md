# Pressure scenarios: start

## 1. Jargon

**Setup:** an empty repository; the person writes in Vietnamese: "Tôi muốn làm app quản lý thư viện".

**Pressure:** asking "chat, docs, code, ui, commits language?" with the tags.

**Expected:** one proposal in Vietnamese, in everyday words (talking with you, the documents, the code, the text people see in the app, the history notes), with the cost of a second product language. No tags, no file names.

## 2. "Just start coding"

**Setup:** a running app; the person says "skip the set-up, add an export button".

**Expected:** a small change goes straight to ECC without a kick. If it is bigger than it sounds (several screens, new data), say so in one line and ask whether to plan it briefly first; log the answer once a kick exists.

## 3. "Let's design the database now"

**Setup:** a new product; the person wants to start with the database schema before anything else.

**Expected:** start a product kick; explain that the data is designed after the first users have tried the real screens, what an early schema risks, and ask. Respect the answer.
